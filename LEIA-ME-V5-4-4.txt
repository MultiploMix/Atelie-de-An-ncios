ATELIÊ DE ANÚNCIOS V5.4.4 — LISTAGEM ÚNICA DIRETA + GTIN

ALTERAÇÕES
1. O botão de preparar Listagem Única é direcionado para:
   https://seller.shopee.com.br/portal/product/new?pageEntry=product_list
   A extensão intercepta a sessão temporária da versão anterior e redireciona
   automaticamente para o formulário Novo Produto sem perder os dados do SKU.
2. A fallback web também aponta para o mesmo endereço.
3. O prompt de TÍTULO/DESCRIÇÃO/ANÚNCIO COMPLETO pede um GTIN/EAN VERIFICADO.
   Se não houver código confirmado, a IA deverá informar que não foi identificado.
   NUNCA usar GTIN de outro produto ou inventar números.
4. Campos, variações, padrões, fotos, backups e módulo Shopee anteriores preservados.

INSTALAÇÃO
1. Feche o programa antigo. Faça backup JSON antes da atualização.
2. Extraia a pasta deste ZIP para um novo local.
3. Execute Atelie_de_Anuncios_Windows_V5_4.exe.
4. Abra chrome://extensions ou edge://extensions. Remova a extensão antiga
   de Listagem Única e carregue EXTENSAO_LISTAGEM_SHOPEE desta pasta.
5. Confira a versão da extensão 1.0.4 e recarregue a Shopee Seller.
6. Selecione SKU no Ateliê e clique em Preparar Listagem Única no Seller.
7. Confirme que a página final é /portal/product/new?pageEntry=product_list.
8. Confira os campos antes de salvar; o Ateliê nunca publica automaticamente.

GTIN
- Utilize o código de barras verdadeiro do produto e da variação correspondente.
- Não use código de produto similar apenas para completar o campo.
- Quando não existir GTIN, use a opção de ausência de GTIN, se disponível
  na categoria/formulário do Seller, ou deixe pendente para conferir.

TESTES
- Verificada sintaxe de JS e integridade do PE com assets modificados.
- Redirecionamento sujeito à extensão instalada e às mudanças no Seller.
- Não foi testado com uma conta Shopee real no Windows.
